# DISCERN Insights

Aplicação web que avalia páginas de saúde com o instrumento DISCERN. A documentação completa, alinhada ao código atual, está em [docs/DOCUMENTACAO.md](docs/DOCUMENTACAO.md).

Itens adiados estão em [docs/FUTURE_IMPROVEMENTS.md](docs/FUTURE_IMPROVEMENTS.md).

## Rodar localmente

Node 18 ou mais novo.

```bash
npm install
npm run dev
```

A aplicação sobe em http://localhost:9002. As variáveis de ambiente, o banco e o fluxo de análise estão na documentação.
